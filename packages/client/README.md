# @hive/client

> Reusable client library for Hive (Node.js).

## Purpose

Wraps the MCP client SDK with Hive-specific helpers: bearer-credential storage, type-safe Tool wrappers, and convenience builders for common flows.

> **Status (v0.1):** intentionally empty. Lands when the MCP transport surface is implemented in [PRY-006](https://github.com/hivemine-ai/hive-vault).
